# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [Unreleased]

Аудит и исправления безопасности/надёжности. Ниже перечислены изменения,
которые затрагивают поведение или данные пользователя.

### Added

- `MAKOTERM_NO_DEMO` — не создавать демонстрационные данные при первом запуске.
- `MAKOTERM_DEBUG` — отладочный лог SSH (путь к файлу, или `1` для `~/.makoterm.log`).
- Запрос парольной фразы для зашифрованных приватных ключей.
- Keepalive-запросы, чтобы сессия не разрывалась за NAT и на idle-файрволах.
- Поддержка `~` в поле Key Path.
- CI (GitHub Actions): форматирование, `go vet`, `go test -race`, сборка, staticcheck.
- Тесты `sshclient` с настоящим SSH-сервером в процессе теста (TOFU, смена
  ключа, отказ пользователя, зашифрованные ключи).
- Тесты инвариантов рендера: UI никогда не выше терминала.
- `scripts/go.sh` — запуск `go` с кэшами внутри репозитория (для песочниц и
  офлайн-сред).

### Fixed

- **Удаление данных было «мягким».** `gorm.Model` включал `DeletedAt`, поэтому
  удалённые хосты оставались в файле БД вместе с паролями в открытом виде.
  Теперь удаление физическое, а освободившиеся страницы обнуляются
  (`secure_delete` + `VACUUM`).
- **Режим журнала WAL заменён на `DELETE`.** В WAL предыдущие версии страниц
  остаются в файле `-wal` до checkpoint'а, поэтому пароль удалённого хоста
  оставался читаемым в sidecar-файле даже после `secure_delete` и `VACUUM`.
- **Корневую группу можно было удалить из интерфейса**, что каскадом уничтожало
  все группы и хосты. Корень скрыт из списка, и БД отказывается его удалять или
  переименовывать; повреждённые базы (без корня, с «осиротевшими» группами)
  автоматически восстанавливаются при запуске.
- **Демо-данные возвращались после удаления**: они создавались каждый раз, когда
  число групп становилось нулевым. Теперь демо-данные создаются не более одного
  раза на базу (маркер в таблице `settings`).
- **Layout выходил за пределы терминала.** `lipgloss.Height()` — это минимум, а
  не максимум: при прокрутке списка добавлялись строки индикаторов `↑`/`↓`, и
  нижняя часть интерфейса уезжала за экран. Колонки теперь рендерятся строго
  заданной высоты, длинные значения обрезаются, а не переносятся.
- **Скроллинг «залипал».** Позиция окна выводится из позиции курсора
  (`ensureVisible`), поэтому выделение больше не уходит за пределы видимой
  области при движении вверх и после изменения размера терминала.
- **Устаревшие алгоритмы и `known_hosts`:** запись ключа выполняется для
  фактического `host:port` и совпадает по формату с OpenSSH.
- **Смена host key** теперь печатает оба отпечатка (полученный и известный) для
  сравнения.
- **Зашифрованные ключи молча игнорировались**, что выглядело как непонятная
  ошибка аутентификации.
- **`fmt.Scanln`** для «Press [Enter]» срабатывал мгновенно на оставшемся вводе;
  теперь используется общий буферизованный stdin.
- SQLite: `busy_timeout`, права 0600 на файл БД и журналы, одно соединение,
  включение foreign keys **после** миграции (иначе запуск падал с
  `FOREIGN KEY constraint failed`), идемпотентная миграция (схема больше не
  пересобирается при каждом запуске).
- `a`/`e` больше не открывают форму без корректной цели; форма без полей не
  вызывает панику (деление по модулю на ноль).
- **CI падал на минимальной версии Go.** Матрица собирала `1.24.x`, тогда как
  `go.mod` требует `1.25.0` (из-за `golang.org/x/crypto v0.52.0`), а
  `GOTOOLCHAIN=local` запрещает подкачивать более новый тулчейн. Минимум в CI,
  README и документации приведён к `1.25.x`.

### Changed

- Панель DETAILS показывает фактический метод аутентификации
  (`Password (stored)`, `SSH Agent / prompt`, путь к ключу) вместо общего
  «SSH Agent / Password».
- Демонстрационные хосты используют документационные адреса (RFC 5737) и
  обезличенные логины вместо `127.0.0.1` и реального имени пользователя.
- Версия в `go.mod` — `1.25.0` (ранее было указано несуществующее `1.26.3`).
  Это фактический минимум: `golang.org/x/crypto v0.52.0` и остальные
  `golang.org/x/*` требуют Go ≥ 1.25.0, поэтому и матрица CI начинается с
  `1.25.x`, а не с `1.24.x`.

### Removed

- Мёртвый тип сообщения `errMsg` и неиспользуемые стили.

### Breaking changes

- Базы, созданные этой версией, **не читаются** прежними версиями: колонки
  `deleted_at` больше не поддерживаются.
- При первом запуске новой версии ранее «мягко удалённые» записи удаляются
  физически (об этом сообщается в stderr). Данные, удалённые пользователем в
  прежних версиях, восстановлению не подлежат — это и есть цель исправления.
