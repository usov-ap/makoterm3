# Руководство пользователя

## Запуск

```bash
./makoterm
```

Или из исходников:

```bash
go run .
```

Приложение не принимает аргументов командной строки и не использует переменных окружения.

## Первый запуск

При первом запуске автоматически происходит:

1. Создаётся файл базы данных `~/.makoterm.db` с правами 0600
2. Заполняются демонстрационные данные:
   - Группа **Root** (корневая, скрытая)
   - Группы **Production** и **Development**
   - Три демо-хоста: Web Server, DB Server, Staging

## Главный экран

Интерфейс состоит из трёх зон:

```
┌──────────────────────────────────────────────────────────────────┐
│ 🦈 MakoTerm                                             ? help  │  Header
├─────────────────┬──────────────────────┬─────────────────────────┤
│ GROUPS          │ HOSTS                │ DETAILS                 │
│                 │                      │                         │
│   ▸ Production  │   ▸ Web Server       │   Web Server            │
│     Development │                      │   admin@127.0.0.1:2222  │
│                 │                      │                         │
│                 │                      │   User       admin      │
│                 │                      │   Address    127.0.0.1  │
│                 │                      │   Port       2222       │
│                 │                      │   Auth       SSH Agent  │
│                 │                      │                         │
│                 │                      │   ⏎ Enter to connect    │
├─────────────────┴──────────────────────┴─────────────────────────┤
│ ↑↓ navigate   ⏎ connect   a add   e edit   d delete   ? help    │  Footer
└──────────────────────────────────────────────────────────────────┘
```

### Header

Полноширинная полоса с названием приложения слева и подсказкой `? help` справа.

### Колонки

| Колонка | Содержимое |
|---------|-----------|
| **GROUPS** | Список групп серверов. Активная колонка подсвечена синей рамкой. |
| **HOSTS** | Хосты в выбранной группе. |
| **DETAILS** | Информация о выбранном хосте или группе. |

Текущий элемент отмечен треугольником `▸` и выделен цветом. При прокрутке больших списков появляются индикаторы `↑` и `↓`.

### Footer

Контекстная полоса с горячими клавишами. Содержимое меняется в зависимости от текущего состояния (навигация, форма, подтверждение удаления, справка).

## Навигация

| Клавиша | Действие |
|---------|----------|
| `↑` / `k` | Курсор вверх |
| `↓` / `j` | Курсор вниз |
| `←` / `h` | Перейти в колонку групп |
| `→` / `l` | Перейти в колонку хостов |
| `Enter` | Войти в колонку хостов (из групп) или подключиться (из хостов) |

При смене группы в левой колонке содержимое колонки хостов обновляется автоматически.

## Управление серверами

### Добавление группы

1. Фокус должен быть в колонке **GROUPS**
2. Нажмите `a`
3. Откроется форма с полем **Name**
4. Введите название группы
5. Нажмите `Enter` для сохранения или `Esc` для отмены

### Добавление хоста

1. Фокус должен быть в колонке **HOSTS**
2. Нажмите `a`
3. Откроется форма с полями:

| Поле | Описание | Обязательное |
|------|----------|:---:|
| **Name** | Отображаемое имя хоста | Да |
| **Address** | IP-адрес или hostname сервера | Да |
| **Port** | SSH-порт (по умолчанию 22) | Да (1–65535) |
| **User** | Имя пользователя SSH | Нет |
| **Password** | Пароль (отображается как `•••`) | Нет |
| **Key Path** | Путь к приватному ключу | Нет |

4. Переключение между полями: `Tab` / `Shift+Tab` (или `↓` / `↑`)
5. `Enter` — сохранить, `Esc` — отменить

Валидация: имя и адрес не могут быть пустыми, порт должен быть числом от 1 до 65535.

### Редактирование

1. Выберите группу или хост
2. Нажмите `e`
3. Форма откроется с текущими значениями полей

### Удаление

1. Выберите группу или хост
2. Нажмите `d`
3. Появится диалог подтверждения с красной рамкой:
   - `y` — подтвердить удаление
   - `n` или `Esc` — отменить

При удалении группы рекурсивно удаляются все вложенные подгруппы и хосты.

## Подключение к SSH

1. Перейдите в колонку хостов (`→` или `l`)
2. Выберите хост (`↑`/`↓`)
3. Нажмите `Enter`

Приложение передаёт управление терминалом SSH-сессии. Вы получаете полноэкранный доступ к удалённому серверу.

### Первое подключение к новому серверу

При подключении к серверу, ключ которого отсутствует в `~/.ssh/known_hosts`, появится запрос (аналогично OpenSSH):

```
The authenticity of host '10.0.0.1:22' can't be established.
ssh-ed25519 key fingerprint is SHA256:xxxxx.
Are you sure you want to continue connecting? (yes/no):
```

Введите `yes` для принятия ключа.

### Возврат из SSH-сессии

- Введите `exit` в удалённом шелле, или
- Нажмите `Ctrl+D`

Вы автоматически вернётесь в MakoTerm с сохранённой позицией курсора.

### Изменение размера терминала

Изменение размера окна терминала во время SSH-сессии автоматически транслируется на удалённый сервер через SIGWINCH.

## Панель деталей

### Для хоста

Панель показывает:
- Имя хоста (жирным)
- Строку подключения (`user@address:port`)
- Поля: User, Address, Port
- Метод аутентификации (Key или SSH Agent / Password)
- Подсказку `⏎ Enter to connect`

Порт отображается в строке подключения только если он отличается от 22.

### Для группы

Панель показывает:
- Имя группы
- Количество хостов в группе
- Подсказку `→ to browse hosts`

## Справка

Нажмите `?` для открытия экрана со всеми горячими клавишами. Закрывается нажатием любой клавиши.

## Ошибки

При возникновении ошибки (сеть, база данных, валидация) отображается диалоговое окно с описанием. Нажмите любую клавишу для возврата к навигации.
